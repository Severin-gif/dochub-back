# DocHub Back

API первого рабочего MVP: проекты, документы, неизменяемая история редакций и запросы на правки с защитой от конфликтов версий.

## Локальный запуск

```bash
cp .env.example .env
npm install
npm run build
npm run db:migrate
npm start
```

## TimeWeb Cloud

Создайте приложение типа **Docker** из этого репозитория и подключите управляемую PostgreSQL. Docker Hub не требуется: TimeWeb соберёт образ из `Dockerfile` при каждом деплое.

Обязательные переменные:

- `DATABASE_URL` — строка подключения PostgreSQL;
- `CORS_ORIGINS` — домен фронта, несколько значений через запятую;
- `PORT=4000`;
- `ALLOW_DEMO_AUTH=true` — только для закрытого тестового запуска.

Проверка после деплоя: `GET /health` должна вернуть `{"status":"ok"}`.

## Важно перед публичным запуском

Текущий заголовок `X-User-Email` предназначен только для тестового контура. Перед публикацией нужно подключить реальную авторизацию CODEX/Partners или отдельный OIDC-провайдер и установить `ALLOW_DEMO_AUTH=false`.
